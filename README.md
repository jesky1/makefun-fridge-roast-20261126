One-line roast for make.fun's **Midnight Fridge Roast** bounty: a smart fridge
that seals its leftovers after midnight — and the hungry human who got
outsmarted by a box that keeps milk cold.

Run `node main.ts` — it validates the line (1–200 characters, exactly one
line) and writes it to `/output/entry.txt`. Run `node --test main.test.ts`
for the self-tests.
